WhatsApp AI 客服

顾客在 WhatsApp 问问题，AI 24 小时替你回。答不上来的，才叫你。

装在你自己的服务器上 聊天记录和顾客资料都在你的机器里，我们碰不到。你随时可以导出或停用。
整个流程大概 3–5 天
  1. 开通前准备（今天就能做）
  2. 申请 WhatsApp 商业号（要等 1–3 天审核）

  4. 填资料、上线（30–60 分钟）

第一部分 · 开通前准备

三样东西，缺一样都装不起来。建议今天就开始准备——第二部分要等官方审核， 你正好可以在等待期间把这些做完。

1

一个没在用的手机号

⚠️ 这一条最重要，请务必看完 号码接入之后，手机上的 WhatsApp Business App 就收不到这个号的消息了。 所有顾客消息会进到网页后台。

这是 WhatsApp 官方的规定，不是我们的限制。所以 千万不要用你的私人号或正在用的主力客服号，建议专门办一张新卡。

要求：能收短信验证码。

2

一台云服务器

内存2GB（1GB 勉强能跑，不推荐）
系统Ubuntu 24.04
硬盘20GB
机房新加坡（东南亚速度最快）
去哪开OVHcloud / DigitalOcean / Vultr 都可以，约 RM30/月
⚠️ 开好之后一定要做这一步 到云服务商的控制台，把 80 和 443 端口在「安全组 / Firewall」里放行。

不做这一步，后面申请不到 HTTPS 证书，网页打不开。 这是所有安装失败原因里最常见的一个。

开好后记下：公网 IP（形如 139.99.89.252）和 root 密码。

3

顾客最常问的 10 个问题和答案 ⭐

这一步决定机器人聪不聪明，也是最花时间的一步。 这里写的是只属于你这家店的事实——价格、地址、时间、规矩。机器人只会照说，一个字都不会编。

这一行的通用常识（比如餐饮的过敏原、订位规矩、外送平台怎么处理）机器人自己就懂， 你不用写。它会用常识帮顾客判断和引导，但只有你写的才会当成你家的承诺说出口。

建议现在就打开记事本，把这些写下来：

  • 营业时间（包括公共假期开不开）
  • 地址、附近地标、有没有停车位
  • 送不送货、送到哪些区、运费多少、几天到
  • 可以怎么付款
  • 能不能退换货、条件是什么
  • 主要卖什么、价格大概什么范围
常见错误：把「指令」当成「资料」 ❌ 「请礼貌地接待顾客，不确定就转人工」—— 这是给机器人的指令，系统里本来就有
✅ 「每天早上 9 点到晚上 9 点营业，公共假期照常开」—— 这才是顾客问题的答案

第二部分 · 申请 WhatsApp 商业号

🕐 这一步要等 1–3 天 操作本身 30 分钟，但 WhatsApp 官方（Meta）审核要 1–3 天。 建议尽早提交。

到 ycloud.com 注册账号，然后：

① 选对入口（很容易选错）

WhatsApp 账户 → 创建渠道账号 → WhatsApp Business APP 共存
不要选普通的「WhatsApp Business API」新建号流程 必须选「共存」。选错了要重新来过。

② 完成 Meta 授权

YCloud 会弹出 Meta 的授权窗口，按提示走：选 WhatsApp Business App → Continue → 核对企业资料 → 时区选 Asia/Kuala Lumpur → 确认企业网站 → Finish。

几个常见卡点：

现象怎么办
按钮一直转圈、变灰刷新页面，关掉提示弹窗后重试
点了没反应，弹窗不出来用真实鼠标点，别用浏览器插件自动点
要求邮箱 / 短信验证码正常流程，必须账号持有人本人完成
企业资料的 Next 点不动网站字段清空重填，用 Meta 自动带出的网址

③ 拿 API Key

YCloud 控制台 → Developers → API Key，点「查看」可能要验证码， 验证后会显示完整的 Key。先复制存好，第四部分要用。

这一步卡住了？找我们 这是整个流程里最容易卡的地方，我们可以代你办

第三部分 · 安装系统（5 分钟）

① 登录你的服务器

Windows：按 Win + R → 输入 cmd → 回车，然后输入：

ssh root@你的服务器IP

Mac：打开「终端」，输入同样的命令。

第一次登录会问 Are you sure you want to continue connecting?，输入 yes 回车。
输密码时屏幕上不会显示任何字符，这是正常的，输完直接回车。

② 粘贴这一条命令

curl -fsSL https://oceanlightglobal.github.io/wa-cs-install/install.sh | sudo bash

Windows 命令行里粘贴是点鼠标右键，不是 Ctrl+V。

③ 等 3–8 分钟

它会自己安装 Docker、申请 HTTPS 证书、启动服务。跑完会打印最重要的两行：

════════════════════════════════════════════
  ✅ 安装完成！
════════════════════════════════════════════

    后台地址：  https://139-99-89-252.sslip.io
    登录密码：  Kf7mQxRtLpZa
💡 不用买域名 那个 139-99-89-252.sslip.io 是自动生成的免费网址，直接指向你的服务器， 而且有正规的 HTTPS 证书。

想用自己的域名？先把域名 A 记录指向服务器 IP，然后命令改成 ... | sudo bash -s -- --domain cs.你的品牌.com

第四部分 · 填资料，上线

浏览器打开刚才打印的地址，用打印的密码登录。四步向导：

1

改密码

把系统给的随机密码改成你记得住的。这是以后进后台的钥匙。

🔑 接着会出现一串恢复码，只显示这一次 形如 WACS-XXXX-XXXX-XXXX。请当场截图或抄下来。 忘记密码时用它重置——我们这边也查不到（只存了指纹，没存原文）。 它同时也在你下载的备份文件里。
2

连接 WhatsApp

填两样，都在 YCloud 后台：

  • API Key —— Developers → API Key
  • WhatsApp 商业号码 —— 格式 60123456789， 国际格式，不要加 +，不要空格横杠

点「测试连接」，显示绿色的「连接成功」就对了。系统会自动帮你配好回调地址。

之后还要在「连接设置」里填 AI 接口的地址、密钥和模型名—— 这三样我们会发给你。

3

选行业 + 填本店资料 ⭐

先选行业。选了「餐饮」，机器人就自带这一行的常识：过敏原和清真、怎么推荐菜、 订位要问什么、Grab／foodpanda 的单怎么处理、投诉怎么接。这些你一条都不用写。

然后把你在第一部分写好的内容贴进本店资料。点「插入示例模板」可以看格式。

这一步决定产品好不好用，其他步骤都只是铺垫。保存后立刻生效，随时可以补充。

懒得从头写？右上角有「从网址导入」——贴一个你自己的网页， 机器人整理成草稿填进框里让你改，你点保存才算数。

4

发条测试消息

用另一部手机给你的商业号发一句「你们几点营业？」， 页面会实时显示收到消息、机器人已回复。看到 ✅ 就通了。

💡 上线前先自己试 后台「机器人」页有个「试一试」——直接打一句顾客可能问的话，当场看它怎么答， 不用骚扰真实号码。

答得不好？改本店资料，保存，再试。改到满意再对外。

装好之后要知道的三件事

① 红点闪 = 有人在等你

机器人搞不定的时候会转给你，后台亮红点、响提示音。 你直接在框里打字回复，顾客在 WhatsApp 上就收到了。 回完点「交还给机器人」，它继续自动答。

② 那个倒计时是 WhatsApp 的规定

24 小时窗口 顾客给你发消息后，你只有 24 小时能自由回复，超时只能发审核过的模板消息。

所以每个对话上面有倒计时。显示「窗口已关闭」时输入框会锁上—— 这不是故障，是 WhatsApp 的规定。顾客再发一条消息就会重新开始。

③ 每月下载一次备份

「系统」→「下载备份」，存到你自己的电脑或云盘。换服务器时能一键还原。

常见问题

机器人会不会乱说话，得罪我的客户？

关于你这家店的事实——价格、地址、时间、规矩——它只会照着你写的说，一个字都不会编， 也不会替你承诺任何折扣或赔偿金额。

你没写的事，它不会硬答，但也不会一句「查不到」就把顾客丢给你： 它会说明这一行一般是怎么处理的、问清关键信息，真需要你出面时再交给你，而且信息已经问齐了。 上线前你可以用「试一试」先自己问几句。

它会主动给我的客户群发广告吗？

不会。它只被动回复顾客发来的消息，不会主动发起对话。

我的客户数据安全吗？

所有聊天记录存在你自己的服务器上，我们碰不到。 系统日志里顾客手机号自动打码（6012*****89），符合 PDPA。

机器人答错了怎么办？

八成是本店资料没写清楚。补进去，保存，立刻生效，不用重启。

更省事的办法：你人工回完那条之后，在收件箱点「学进资料」—— 机器人会把这一问一答整理成一条资料，你确认一下就加进去了。 下次再有人问同样的事，它自己就能答。用得越多，找你的次数越少。

忘记后台密码了怎么办？

登录页点「忘记密码」，有三条路：

  • 用 WhatsApp 收验证码（最快）——用你自己的手机给你的商业号发一条 RESET， 几秒后收到 6 位码。前提是你在「机器人 → 通知老板」填过自己的号码，建议装好就去填。
  • 用恢复码——装机时那串 WACS- 开头的码，备份文件里也有一份。
  • 在服务器上重置——前两条都不行时找我们，三行命令搞定，其他数据一点都不动。

能随时不用吗？

能。数据一键导出备份，服务器是你的，随时停。
